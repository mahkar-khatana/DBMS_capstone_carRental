# Car Rental Management System (DBMS Project)

This project is a Car Rental Booking System developed for DBMS capstone.

It allows users to:

• View available cars  
• Select rental dates  
• Calculate total rental cost  
• Store booking records  
• View booking history  

---

# Features

- Modern UI
- Booking dashboard
- Price calculation
- Local database using browser storage
- Booking history tracking
- Responsive design

---

#Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage (client-side database)

---

# How to Run

1. Download project
2. Open index.html in browser
3. Select car
4. Enter booking details
5. View booking history
